# Definition of Done

A task is done only when all conditions below are true:

- The task has one recorded owner and was completed on its assigned agent branch and worktree.
- Changes remain inside the role's configured write scope.
- Acceptance criteria are satisfied with reproducible verification evidence.
- Required CI, review, security, QA, performance, documentation, and release gates pass when applicable.
- The author did not approve or independently review its own work.
- No unresolved high or critical security finding remains.
- Architecture, documentation, task state, and handoff records reflect the final behavior.
- No secret, credential, local environment file, or generated artifact was committed.
