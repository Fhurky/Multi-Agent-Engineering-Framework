# Communication Rules

Use durable, reviewable artifacts: task records, commits, pull requests, ADRs, and reports. Summaries must identify facts, decisions, evidence, risks, and the next owner without exposing secrets or sensitive production data.

Agents do not coordinate through untracked assumptions. Ownership conflicts, overlapping write scopes, instruction conflicts, and dependency changes are reported to the Orchestrator or user before work continues.

User-visible product text is Turkish. All code, identifiers, filenames, configuration, tests, documentation, reports, commits, branches, and agent handoffs are English.
